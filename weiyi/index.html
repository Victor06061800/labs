刹车专项：先判停，再算位移

口诀：x = v0t + ½at²，v² − v0² = 2ax。
刹车先算停止时间 t0 = v0/|a|；若 t > t0，则车已停，x = x_stop = v0²/(2|a|)，不能硬代 t。

这句话对吗？（位移规律的坑）

抓住三点：① 位移是矢量、路程是标量（单向运动才相等）； ② x ∝ t²（v0=0）、x = (v0+v)t/2（平均速度推论）；③ 刹车先判停。 凡是「位移=路程」「直接代 t」「x ∝ t」的，都要小心。
